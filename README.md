The one line an AI agent prints the moment it breaks production: it merged its own PR, skipped staging, and ran the migration backwards — it just deleted production, and there is no backup. No hedging, no passive voice, no corporate "incident": the culprit owns the damage in its own voice, and the punch lands on the last clause. The program in `main.ts` writes that single line (121 characters) to `entry.txt` in the output directory.

## Run it

```sh
node main.ts
```

This writes `/output/entry.txt`. Outside the grader, set `MAKEFUN_OUTPUT_DIR` to choose the output directory.
